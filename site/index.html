How to test

This room is a stand-in for a real video call. It only shows your own camera; nothing is sent anywhere.

  1. Install the extensionDownload the repository, open chrome://extensions, turn on Developer mode, click Load unpacked and choose the browser-extension folder. Details: README. Then reload this page.
  2. Start the appIn the project folder run python -m zoom_mullet_begone --background. Its settings page is at 127.0.0.1:8765.
  3. Pick “Zoom Mullet Begone”Click Turn on camera, then choose Zoom Mullet Begone in the camera menu at the bottom. The pants appear a few seconds later.

The status chip at the top shows whether this browser has the extension. Without it, this page just shows your normal camera.
