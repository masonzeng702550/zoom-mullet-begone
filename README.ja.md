# meet-pants

[English](README.md) | [繁體中文](README.zh-TW.md) | **日本語** | [한국어](README.ko.md)

ビデオ会議用のバーチャルパンツです。meet-pants は姿勢推定モデルで脚を追跡し、脚の動きに合わせてパンツを描画して、その映像を仮想カメラに送ります。Google Meet、Zoom、Teams などのアプリで、このカメラを選んで使えます。

## 機能

- **脚ごとに追従するパンツ**：腰、太もも、膝、すねを追跡し、パンツの輪郭も実際のシルエットに沿って合わせます。太い脚も細い脚も、両脚のあいだもきちんと隠れます。
- **映像になじむ描画**：照明、色味、カメラのノイズを映像に合わせ、輪郭をぼかし、前腕や手はパンツより手前に表示します。
- **近距離でも動作**：カメラに近づきすぎて腰と脚しか映らないときは、別の姿勢推定モデルに切り替わります。
- **シャツに合わせたコーディネート**：上着に合うパンツのスタイルと色を自動で選びます。自分で指定することもできます。
- **設定ページ**：ローカルの Web ページでスタイルと色を選べます。会議相手に届いている映像のライブ表示もあります。
- **バックグラウンドモード（macOS）**：メニューバーに常駐し、会議アプリがカメラを使っているときだけ動作します。

パンツは 3 種類（ネイビーのスラックス、カーキのチノパン、インディゴのジーンズ）が付属し、どれも色を変えられます。

## 現在の状況

- macOS（Apple シリコン）で開発・テストしています。
- Windows と Linux でも、下記の仮想カメラがあれば通常モード（フォアグラウンド）で動くはずですが、まだテストしていません。これらの OS では、バックグラウンドモードで会議を検出できません。
- 腰が映っているあいだは常にパンツを描画します。「パンツをはいていない」状態の自動検出は今後の予定です。

## 必要なもの

- Python 3.11 または 3.12
- 仮想カメラのドライバー：
  - **macOS / Windows**：[OBS Studio](https://obsproject.com/) 30 以上。一度 OBS を開いて「仮想カメラ開始」（Start Virtual Camera）を押し、OBS を終了します。meet-pants は OBS がインストールするカメラドライバーを使うので、普段 OBS を起動しておく必要はありません。
  - **Linux**：[v4l2loopback](https://github.com/umlaeute/v4l2loopback)（Chrome に表示させるため `sudo modprobe v4l2loopback exclusive_caps=1` で読み込みます）。

## インストール

```bash
uv venv --python 3.11
uv pip install -e ".[dev]"
python scripts/download_models.py
```

`download_models.py` は姿勢推定・セグメンテーション・フォールバック用のモデル（約 75 MB）を `models/` にダウンロードします。

macOS では、初回起動時にターミナルアプリのカメラ使用許可を求められます。

## クイックスタート

**バックグラウンドモード（macOS、おすすめ）：**

```bash
.venv/bin/python -m meet_pants --background
```

メニューバーにパンツのアイコンが表示されます。会議に参加してカメラに「OBS Virtual Camera」を選ぶと、約 2.5 秒後にパンツが表示されます。

**フォアグラウンドモード（すべての OS）：**

```bash
.venv/bin/python -m meet_pants
```

プレビューウィンドウが開き、すぐに仮想カメラへ映像を送ります。

## 会議や Web サイトで使う

meet-pants は映像を「OBS Virtual Camera」に送ります。OS はこれを通常のカメラとして扱い、内蔵カメラと並べて表示します。カメラを選べるアプリやサイトなら、どこでも使えます。

- **Google Meet**（どのブラウザでも）：設定 → 動画 → カメラ → OBS Virtual Camera。
- **Chrome、Edge、Arc のその他のサイト**：アドレスバーのカメラアイコンから選ぶか、`chrome://settings/content/camera` で全サイト共通に設定します。
- **Safari と Firefox**：サイトごとに確認されるので、カメラの確認画面かサイト設定で OBS Virtual Camera を選びます。
- **Zoom、Teams、FaceTime、Discord、Slack**：各アプリのビデオ設定で OBS Virtual Camera を選びます。

内蔵カメラを使い続けるアプリは、meet-pants では置き換えられません。macOS ではどのアプリも実カメラを直接開けるうえ、システム全体でカメラを差し替える方法がないためです。meet-pants が動いていないとき、仮想カメラには OBS の待機画像が表示されます。

## バックグラウンドモード（macOS）

```bash
.venv/bin/python -m meet_pants --background
```

メニューバーのアイコンは、待機中は線だけ、使用中は塗りつぶしで表示されます。

- **待機中**：カメラはオフで、ほとんど何も動きません（CPU 約 0%、メモリ約 170 MB）。1 秒に 2 回、どれかのアプリが OBS Virtual Camera を開いたかを macOS（CoreMediaIO）に問い合わせます。
- **会議がカメラを開いたとき**：meet-pants がカメラをオンにし、約 2.5 秒後にパンツが表示されます。それまでのあいだ、会議には OBS の待機画像が映ります。
- **会議がカメラを閉じたとき**：meet-pants 自身が送る映像のせいで仮想カメラは「使用中」のままになるため、これを直接は検出できません。カメラの前に 1 分間だれもいなかったら、少しだけ映像の送信を止めて確認し直します。カメラを読んでいるアプリがなければ、カメラをオフにして待機に戻ります。会議のあとも席に座ったままだと、席を離れるか、終了するか、メニューで自動開始をオフにするまで動き続けます。
- **メニュー**：現在の状態、「開啟設定…」（設定を開く）、「會議開鏡頭時自動套用」（会議がカメラを開いたら自動で開始）、「結束 meet-pants」（終了）。

Windows と Linux の `--background` は、会議がカメラを開いたタイミングをまだ検出できないため、常に動作します。

## 設定ページ

meet-pants の実行中に `http://127.0.0.1:8765/` を開くか、プレビューで `S` を押すか、メニューバーで「開啟設定…」を選びます。次のことができます。

- スタイルの選択：カーキのチノパン、ネイビーのスラックス、ジーンズ
- 色の選択：もとの色、プリセット、またはカラーピッカーで任意の色（生地の陰影、織り目、しわはそのまま残ります）
- シャツに合わせる機能のオン／オフ
- 会議に届いている映像のライブ表示（バックグラウンドモード）

変更はすぐに画面へ反映され、次回起動時のデフォルトとして保存されます。`python -m meet_pants --settings` を使うと、カメラを起動せずに設定ページだけを開けます。

設定ページとメニューバーは、今のところ繁体字中国語のみです。設定ページは 127.0.0.1 でのみ待ち受け、ページ自身からの変更しか受け付けないので、ほかの Web サイトから設定を変えられることはありません。設定ファイルで `settings_port: 0` にするとオフになります。

## コマンドラインオプション

| オプション | 説明 |
|---|---|
| `--background` | メニューバーで動作し、会議が仮想カメラを開いたら開始（macOS） |
| `--settings` | カメラを使わずに設定ページだけを開く |
| `--input 1` / `--input clip.mp4` | カメラ番号または動画ファイル |
| `--resolution 1280x720`、`--fps 30` | 取り込み解像度とフレームレート |
| `--model lite` | 速いが精度の低い姿勢推定モデル |
| `--mode always` / `--mode off` | 腰が見えていれば常にパンツを描画／描画しない |
| `--garment jeans_indigo` | このパンツを使う（`dress_navy`、`chino_khaki`、`jeans_indigo`）。シャツに合わせる機能はオフになる |
| `--auto-garment` / `--no-auto-garment` | シャツに合わせる機能のオン／オフ |
| `--no-vcam` | プレビューのみで、仮想カメラには送らない |
| `--no-preview` | 仮想カメラのみで、プレビューウィンドウを開かない |
| `--debug landmarks,masks,mesh,hud` | プレビューのデバッグ表示（`none` で非表示） |
| `--record data/clip.mp4` | 問題の再現用に、カメラの元映像も録画する |
| `--config path.yaml` | 指定した設定ファイルを使う |

**プレビューウィンドウのキー**：`M` パンツのオン／オフ、`P` 次のパンツ（シャツに合わせる機能はオフになる）、`A` シャツに合わせる機能のオン／オフ、`S` 設定ページ、`D` デバッグ表示の切り替え（骨格 → 骨格と人物マスク（紫）・肌（オレンジ） → メッシュ → なし）、`Esc` または `Q` で終了。

プレビューは左右反転して表示されますが、仮想カメラの映像は反転しません。会議アプリが自分の映像を反転表示するためです。デバッグ表示はプレビューにだけ出ます。

## 設定ファイル

設定は、OS の設定フォルダーにある YAML ファイルから読み込みます。

| OS | 場所 |
|---|---|
| macOS | `~/Library/Application Support/meet-pants/config.yaml` |
| Windows | `%APPDATA%\meet-pants\config.yaml` |
| Linux | `~/.config/meet-pants/config.yaml` |

コマンドラインオプションは設定ファイルより優先されます。macOS と Windows では、以前の場所にある `~/.config/meet-pants/config.yaml` が自動で新しい場所へ移動されます。例：

```yaml
garment: chino_khaki
garment_color: "#3c3f44"   # "" はパンツのもとの色
garment_auto: false        # true：シャツに合うパンツを自動で選ぶ
fps: 24
pose:
  pose_every: 2            # N フレームごとに姿勢推定を実行
  segment_every: 2         # N フレームごとに肌／服のセグメンテーションを実行
  segmenter_gpu: true
  fallback: true           # 近距離では RTMPose を使う
```

## パフォーマンス

M4 Pro の MacBook Pro で、720p・30 fps のカメラを使って計測しました。

| 状況 | CPU | メモリ |
|---|---|---|
| バックグラウンドモードで待機中 | 約 0% | 約 170 MB |
| 実行中（上半身が映っている） | 約 30〜40% | 約 650 MB |

負荷を抑えるための工夫：

- 肌／服のセグメンテーションは GPU で実行し、脚が映っているときと、シャツの色を取るときだけ動かします。
- 姿勢推定は 2 フレームに 1 回実行します。速い動きをより正確に追うには `pose_every: 1` にします（CPU が約 3 分の 1 増えます）。
- 近距離用のフォールバックモデルは、初めて必要になったときに読み込みます。MediaPipe が上半身をとらえていて腰が画面外にあるときは実行しません。
- OpenCV はシングルスレッドで動かします。デフォルトではフレームごとの小さな処理まで全コアに分散させ、それだけで CPU の 3 分の 1 を使っていました。
- 姿勢推定モデルは CPU で実行します。macOS の MediaPipe の GPU モードは、フレームごとにメモリリークが起きるためです。`segmenter_gpu: false` にするとセグメンテーションも CPU に戻せます（メモリは約 400 MB 減り、CPU は増えます）。

さらに負荷を下げるには、`--fps 24`（または 20）を指定し、`--no-preview` を付けるかバックグラウンドモードを使います。

## しくみ

**姿勢**：MediaPipe Pose Landmarker が腰、膝、足首を見つけます。MediaPipe は胴体の大部分が映っていないと動作しないため、カメラに近づいて腰と脚しか映らないフレームでは RTMPose が代わりに処理します（OpenMMLab の YOLOX 人物検出器と、26 点の身体・足キーポイントモデルを onnxruntime で実行）。RTMPose の結果は、妥当なときだけ採用します。つまり、腰が画面内にあり、少なくとも片方の膝が見えていて、MediaPipe が肩をとらえている場合は腰が肩より十分下にあることが条件です。両方のモデルが一瞬見失った場合は、パンツがちらつかないよう直前の姿勢を 300 ミリ秒保持します。プレビューには、どちらを使っているかが表示されます（`pose mediapipe`、`rtmpose`、`hold`）。

**脚**：人物マスクと肌／服のセグメンテーションを使い、太ももとすねの複数の位置で脚の幅を測ります。パンツは少なくともその幅で描画し、太ももが触れ合う部分では左右のパンツが中央で合わさります。

**シャツに合わせる機能**：肩から腰のあいだでシャツの色を取り（服の部分だけで、手は含みません）、数秒かけて平滑化します。そのうえで各パンツを採点します。明暗のコントラストが大きいほど高得点で、同系色で明るさも近い組み合わせ（ネイビーにネイビーなど）は減点、上着が鮮やかなときは落ち着いた色のパンツを優先します。パンツが切り替わるのは、別のパンツがはっきり上回った状態が 1.5 秒続いたときだけです。肩が見えている必要があるため、近づきすぎたときは直前の選択が維持されます。

**パンツの素材**：`garments/` の各フォルダーには、正面から見た RGBA の `texture.png` と `garment.yaml` が入っています。`garment.yaml` にはアンカー点（左右の脚それぞれの腰、股、膝、裾）と装飾線（縫い目、縁、折り目、ステッチ）が書かれています。テクスチャを大きく縮小して表示すると細い線が消えてしまうため、装飾線は画面上でくっきりした線として描き、メッシュに沿って曲げます。付属のパンツは `scripts/make_garments.py` で生成しています。

## 開発

```bash
.venv/bin/python -m pytest
```

モデルや `data/` 内の非公開テスト映像が必要なテストは、ファイルがなければスキップされます。`--record` で録画した映像は `data/` に保存され、このフォルダーはコミットされません。
